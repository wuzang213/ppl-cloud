# 评评哩-本地生活分享平台

## 项目简介

面向 C 端的探店分享微服务平台，提供附近店铺、优惠券秒杀与支付、探店笔记 Feed 流、站内搜索等能力。基于 Spring Cloud Alibaba 构建分布式系统，解决高并发、缓存异常、分布式数据一致性、Feed 流分发、搜索索引一致性等问题。

## 核心业务模块

系统采用模块化拆分设计，业务职责清晰、服务解耦彻底，核心包含五大业务模块：

- **用户模块**：负责用户注册登录、身份鉴权、账号权限、设备管理及用户信息维护，支持修改密码（改密后全设备强制重新登录）。

- **店铺模块**：实现周边店铺查询、店铺信息展示、店铺数据统计等能力，并支持到店预约（幂等提交、我的预约、取消）。

- **优惠券模块**：支撑优惠券发布、领取、秒杀、核销全流程，并接入支付宝 / 微信在线支付与支付结果异步通知，通过高并发方案保障秒杀活动的平稳运行。

- **博客内容模块**：主打用户探店笔记发布、动态 Feed 流推送、内容浏览统计、内容排序去重等核心社区能力，构建完整的 UGC 内容生态。

- **搜索模块**：提供站内全文搜索能力，支持笔记与店铺检索、搜索联想；索引数据增量同步、定时对账，并支持全量重建与一致性校验。

## 技术栈

- **框架：**Java 17、Spring Boot 2.7、Spring Cloud Alibaba、Gateway
- **存储：**MyBatis-Plus、MySQL、Redis、Elasticsearch
- **通信：**OpenFeign、OkHttp
- **消息：**Kafka、RabbitMQ、Canal
- **治理：**Nacos、Sentinel、Redis RateLimiter
- **缓存：**Caffeine、OpenResty、Lua 脚本

## 核心技术亮点

1. **多级缓存优化**：搭建多层缓存架构，使用各类缓存防护手段，配合请求合并、过期时间打散、分布式锁，提升热点接口性能。
2. **分布式鉴权**：双 Token 鉴权方案，网关统一验签；登录强制校验基于 `@LoginRequired` 注解 + AOP 切面，令牌刷新与单 / 全设备下线由 Redis Lua 脚本原子执行（JWT 为 RS256 非对称签名）；修改密码后递增令牌版本号，全设备强制重新登录。
3. **秒杀高并发**：脚本完成库存校验与下单去重，异步消息落库，分布式锁防重复消费，延迟消息关闭超时订单；死信补偿前再做防超卖校验。
4. **在线支付**：优惠券订单接入支付宝（网页支付）与微信（H5 / Native）双渠道，抽象 `PayChannel` 渠道注册表并在装配期做 fail-fast 校验；异步通知验签后幂等更新订单状态，另有主动查单任务兜底，本地可用 mock 渠道联调。
5. **站内搜索**：基于 Elasticsearch 提供笔记 / 店铺检索与联想接口；索引侧用「别名 + 版本化物理索引」支持重建后切别名、零停机，数据消费既有 MQ 广播增量同步，失败落表并走死信队列，另有定时对账、失败重试与一致性校验 / 修复接口，并对深分页做防护。
6. **浏览计数统计**：内存队列 + 批量异步更新计数，队列管控、失败重试、事件聚合投递，降低高频请求对 DB 压力。
7. **分布式一致性**：Outbox 本地消息表，Canal 监听 binlog 广播消息；通过消息确认、死信队列、消费幂等、定时对账保障数据最终一致。
8. **Feed 流优化**：推拉结合分发策略，解决博主扇出问题；多源合并去重、滚动分页，缓存故障自动降级。
9. **网关治理**：免登录接口按客户端 IP 做 Redis RateLimiter 限流（默认不信任可伪造的 `X-Forwarded-For`）；路由规则由 Nacos 配置热更新，变更无需重启；网关统一记录操作 IP、方法、路径、状态码与耗时。

## 系统架构能力

- **高可用**：依托Nacos、Sentinel实现服务注册发现、配置热更新、熔断限流、故障降级，避免服务雪崩，提升系统容错能力。

- **高并发**：通过多级缓存、异步消息、批量处理、请求合并等多种优化手段，适配大流量、高并发的C端用户访问场景。

- **高可靠**：完善的消息保障机制、幂等设计、数据对账补偿方案，确保分布式业务数据最终一致性。

- **可扩展**：服务模块化拆分、业务解耦清晰，支持业务功能快速迭代、服务水平扩容，适配业务体量增长。

## 部署与配置

本项目的 Nacos 配置中心配置与数据库建表语句均随仓库提供：

- **Nacos 配置**：见 [`nacos-config/`](./nacos-config) 目录，包含各服务的共享配置（数据库、Redis、RabbitMQ、Canal、Elasticsearch、日志、鉴权等）与网关路由规则，导入方式详见 [`nacos-config/README.md`](./nacos-config/README.md)
- **数据库初始化**：见 [`sql/`](./sql) 目录，按服务拆分为 `blog.sql`、`shop.sql`、`user.sql`、`voucher.sql`

各服务的敏感配置（数据库地址、账号密码、Redis、RabbitMQ、Canal、Elasticsearch、支付凭据等）**不写入代码**，统一通过 Nacos 配置中心下发，配置模板中仅保留 `${}` 占位符。
